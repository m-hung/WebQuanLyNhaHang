# WebQuanLyNhaHang

Clone dự án về máy, và lần lượt chạy các lệnh sau:
    1. cd admin
    2. npm install
    3. npm install react-router-dom
    4. cd ..
    5. cd backend
    6. ./mvnw clean package -DskipTests
    7. cd ..
    8. docker compose up --build -d


Để chạy giao diện web nhà hàng, làm các bước sau:
    1. Vào thư mục client
    2. Chọn file index.html rồi bấm Go Live


Để chạy giao diện admin, làm các bước sau:
    1. Mở terminal ở thư mục gốc (WebQuanLyNhaHang)
    2. gõ cd admin
    3. gõ npm run dev
